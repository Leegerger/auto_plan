# Bonding 排程前端设计规格

本规格将仓库根目录的 `DESIGN.md` 适配为生产排程工具。`DESIGN.md` 提供视觉语言；本文件规定本项目如何使用这些规则。

## Product Direction

- 第一使用者是每日调整排程的业务编辑者；查看者使用同一信息架构，管理员只增加系统管理能力。
- 仅支持桌面浏览器。完整编辑以一个生产周为操作单位，不设计手机或其他设备布局。
- 工作台先回答“现在需要处理什么”，再展示计划摘要。
- 计划只有一处修改入口。计算、历史恢复与每周重置可产生本机临时稿，但预览、共享保存与正式采用都在计划工作区完成。

## Navigation

一级导航固定为：

1. 工作台
2. 排程
3. 需求与资料
4. 版本与采用
5. 系统管理

使用固定左侧导航，宽度 224px；顶部保留品牌、账号、网络与连接状态。业务页面共用一条计划状态列，显示最近采用版、当前共享修订、输入版本、本机临时稿动作数与操作状态。

## Visual Tokens

来源为 `DESIGN.md`，以下规则优先：

- 画布：`#ffffff`；柔和表面：`#f7f7f7`；较强表面：`#f2f2f2`。
- 主文字：`#222222`；正文：`#3f3f3f`；次要文字：`#6a6a6a`；分隔线：`#dddddd`。
- 品牌强调：`#ff385c`，只用于主要动作和品牌焦点。错误使用 `#c13515` 并同时提供图标与文字。
- 字体：`PingFang SC`, `Microsoft YaHei`, `Noto Sans CJK SC`, system sans-serif。所有字距为 0。
- 标题 20 至 28px；正文 14 至 16px；辅助文字不小于 12px。表格数字使用等宽数字。
- 使用 8px 间距体系。工作型区块间距 24 至 32px；表格行高 36 至 40px；排程矩阵使用紧凑行高。
- 工作面板和一般卡片圆角不超过 8px；状态标签和图标按钮可使用胶囊形状。页面区带不做浮卡，卡片不嵌套。
- 最多使用一级轻阴影。主要依赖边框、表面色和留白建立层级。

## Interaction Rules

### Plan State

计划状态统一为：

1. 本机临时稿
2. 预览完成
3. 共享草稿
4. 采用版计划

保存结果未知时进入全域只读状态，并提供原操作编号核实入口。任何新修改都会使已有预览失效。

### Schedule Workspace

- 顶部：生产周选择、十五周导览、线体与机种筛选。
- 主区：所选生产周的“线体 x 日期”矩阵。
- 右侧：所选日期的生产段、顺序、精确工时、容量、切机、问题与动作。
- 本机临时稿以固定状态列和动作抽屉呈现，不占用主矩阵空间。
- 预览先显示摘要、硬冲突、待确认事项和关键指标；完整差异按日期、线体、机种展开。

### Demand And Data

- 需求默认显示“机种 x 十五周”矩阵，同时展示完整需求、按时覆盖、缺口、待确认与变更量。
- 新增需求使用增减量与变更归属日期；Excel、粘贴和原始行是次要工具。
- 基础资料按主资料、参数、日历、确认分区，并提供搜索和表格筛选。
- 表格编辑先形成待提交变更，整批预览通过后再提交。
- 基础资料编辑表格、整批预览明细和错误列表默认每页 20 笔，可选 20、50、100 笔。表格上下均显示分页面板、当前范围与总笔数。
- 搜索涵盖当前类别全部资料；搜索或更改每页笔数后回到第一页。新增行清除搜索并进入新行所在页，翻页保留未提交编辑，预览与提交涵盖整个当前类别。
- 整批预览先列出各类别笔数，一次查看一个类别的分页明细；错误独立分页，保留工作表和原始来源行号。确认提交仍提交整个预览批次。
- 基础资料有未提交编辑、粘贴内容或预览时，切换类别、重新读取、离页及登出须先选择继续编辑或舍弃变更；浏览器刷新或关闭使用原生离开提示。

### Calculation And Reset

- 计算任务负责提交范围、队列状态、候选和差异比较，不直接修改共享草稿。
- 候选套用后返回计划工作区，形成本机临时稿。
- 执行与重置负责登记事实、快照和执行覆盖；重置结果同样先进入本机临时稿。

### Versions

- 版本与采用负责共享草稿、采用版、历史快照、导出与恢复来源。
- 恢复历史只加入服务端引用动作，不复制完整计划到浏览器。
- 已共享或已采用的版本不显示虚假的撤销按钮；只允许建立新草稿。

## Feedback And Safety

- 清空、覆盖复制、舍弃未分配量、全部重排、每周重置和正式采用必须在完整影响预览后确认。
- 本机动作可撤销；已提交保存和采用版不可撤销。
- 加载状态只覆盖受影响区域。错误、未知结果和冲突保留在页面中，并提供下一步。
- 状态不能只靠颜色表达。所有图标按钮需要可访问名称与提示。
- 对话框和抽屉需要焦点管理、Esc 关闭、标签关联与完整键盘操作。
