# 手动排程交互原型（可抛弃）

对应议题：[批量填量、交换机种与改量顺延应怎样操作？](https://github.com/Leegerger/auto_plan/issues/9)。

本轮问题：十五周、18 条线的日常编辑，应以周表格、单线顺序工作台还是范围向导为主？批量填量如何表达选区和数量口径？

## 打开

直接用浏览器打开 `scheduling-interaction-prototype.html`，或在仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/prototypes
```

访问 `http://127.0.0.1:8765/scheduling-interaction-prototype.html?variant=A`。底部箭头切换 A/B/C；输入框外的左右方向键也可切换。

## 本轮可试

- 十五周切换、一周/三周每日视窗、18 条线分组及机种筛选。
- 点击多选、Shift 矩形选区、向导按日期及线体选择范围。
- 每格覆盖填量，以及选区总量均分的备选交互；均非已经确认的规则。
- 逐格预览、示例冲突说明、临时草稿写入和撤销。
- 数量变化率相对示例采用版按整周全部线体计算；所有示例量假定未执行。

可核对的案例：默认选中 L01 的 10/7 和 10/8，将 A 填成 900，会显示 10/7 的数量锁定冲突；只选 10/8 则能写入草稿，再撤销。L02 的 10/8 的 B 是锁零示例，周末为 Holiday 示例。

## 明确限制与待定项

- 示例仅 A/B/C 三个机种、固定日内排列，无真实生产数据，不验证约 40 机种下的完整密度。
- 只模拟数量锁定与 Holiday 检查，没有完整产能、Recipe 切机、CT、良率、跨周确认、执行事实或求解器。不能生成有效正式计划。
- 交换、改量顺延、锁定/恢复按钮只打开讨论卡片，尚未实现对应交互；后续依据用户回答继续制作。
- 总量均分、填量覆盖、冲突阻止整次写入、筛选保留选区、切周清空选区都只是候选设计，未经用户确认。
- 全部修改仅在内存；刷新即重置。不保存、不更新采用版。
- 本议题尚未形成决议。需要用户试用反馈并逐项解决问题后再发布 resolution。
