# 线体良率按机种和月份维护，旧统一值仅用于存量迁移和历史读取

不同机种需要分别设置线体良率，因此线体良率改为按机种和月份维护，同一机种在所有线体共用。旧数据只有全厂统一的月度线体良率，迁移时将各月旧值展开给迁移时已有的所有机种，作为可分别调整的起始值，以保持迁移前后的计算结果一致。旧统一值的兼容范围限于存量迁移和历史读取；新增输入必须明确指定机种，避免漏填机种时继续套用全厂值。

## Status

Accepted

## Considered Options

- 永久保留统一值作为缺失机种参数的后备值：会掩盖新机种尚未设置线体良率的问题，因此不采用。
- 清空旧值后要求逐机种重新填写：会使已有计划在补齐参数前无法完整计算，因此采用展开旧值作为起点。
- 继续接受缺少机种的旧导入格式并自动应用到所有机种：会使一次导入的影响范围不明确，因此新导入统一要求指定机种。

## Consequences

- 线体良率和机种良率仍分别维护，计算时取对应机种、月份的两项因子相乘，不合并为单项良率。
- 新月份沿用现有补月份机制，按机种分别承接上月值，已有值不覆盖。没有可承接值时标示缺资料，并阻止受影响的自动排程；不套用其他机种的值或补为 100%。
- 投入使用投入日所在月份的良率，产出跨月不切换；在制品使用重置周周一所在月份的良率。
- 保留同投入日、同机种跨线合计后套用良率，再依 Cycle Time 分摊和逐笔向上取整的规则。在制品仍按现有规则换算、取整和确定产出日。
- 画面编辑、贴表、Excel 和 JSON 输入均要求月份、机种和良率；缺少机种的旧格式拒绝导入，并提示使用新格式或新模板。
- 原始输入版本和历史计划保留当时的数据与结果，查看历史不套用最新良率。恢复到当前工作区编辑时使用最新参数重算，延续现有版本行为。
